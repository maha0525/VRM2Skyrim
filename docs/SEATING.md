# 着席時の高さ調整ガイド (椅子・ベンチの位置補正)

VRM アバターは Skyrim の標準体型と比べて頭身や脚の長さが異なることが多く、そのまま椅子やベンチに座らせると「座面より上に浮いてしまう」または「座面に深く沈み込んでしまう」ことがあります。

VRM Skyrim Converter には、アバターの骨格から座ったときの腰の高さを計算し、**椅子やベンチに座っている間だけ自然な高さへ補正する機能**が備わっています。

---

## 1. 必要な環境

- **SKSE64**（`skse64_loader.exe` からゲームを起動すること）

> [!NOTE]
> 着席時の高さ補正には SKSE64 の関数（`NetImmerse.SetNodeLocalPosition`）を使用します。SKSE64 がない環境でもフォロワーは通常通り椅子に座りますが、高さのオフセット補正は行われません。

---

## 2. ウィザードでの設定方法（STEP 03）

この機能は**初期状態でオン（自動計算）**になっています。細かく調整したい場合は、**STEP 03（戦闘スタイルと基礎能力）** の下部にある **「椅子の座り位置（SKSE64 使用時）」** を開いてください。

| 設定項目 | 説明 |
| :--- | :--- |
| **着席時の高さを調整する** (`sitting_enabled`) | オンにすると、フォロワーが椅子やベンチに座ったときに高さを補正するスクリプトを同梱します（初期値：オン）。 |
| **体型から高さを自動計算する** (`sitting_auto`) | 元の VRM の脚の長さと Skyrim 標準の着座姿勢を比べて、ちょうど座面に腰が乗る高さを自動で算出します（初期値：オン）。 |
| **高さの微調整 (cm)** (`sitting_offset`) | 自動計算した位置からさらに手動で上下させたい場合に入力します。プラス（例：`+2.5`）で上に持ち上がり、マイナス（例：`-2.0`）で下に下がります。「自動計算」をオフにした場合は、この数値だけがそのまま使われます。 |

---

## 3. ゲーム内での動きと調整のコツ

- **座ったときだけ働き、立ち上がると元に戻ります**
  フォロワーが椅子やベンチに座り始めると自動で高さが補正され、立ち上がると元の身長・位置へ戻ります。歩行時や戦闘時の見た目に影響することはありません。
- **ゲーム内で座り位置を見てから微調整したいとき**
  1. まずは初期設定（自動計算オン、微調整 `0`）のまま変換して、酒場の椅子などで座り姿を確認します。
  2. 「もう少しだけ低く座らせたい」と感じたら、ウィザードの微調整に `-1.5` や `-2.5`（cm）を入れて再作成します。
  3. 逆に「スカートが座面にめり込むので少し浮かせたい」という場合は、`+1.5` や `+3.0`（cm）のようにプラスの値を入れると綺麗に収まります。

---

## 4. 技術仕様（開発者向けリファレンス）

- **算出ロジック**
  Blender でのモデル変換時に、VRM の大腿・下腿ボーン長と Skyrim 標準骨格の着座アニメーション姿勢（`IdleChairFrontEnter` / 標準座面高）の差分から推奨オフセットを算出し、`conversion.json` に記録します。
- **ゲーム内での適用方法**
  - 生成されるフォロワーの Actor レコードに専用スクリプト（`VRM2SkyrimSeatingScript.pex`）をアタッチし、設定されたオフセット量（Skyrim 内部単位：1 cm ≈ 0.70015 ユニット）をプロパティとして渡します。
  - `OnSit` / `OnGetUp` イベントおよび着席状態の監視により、着席中のみスケルトンのルートノード（`NPC Root [Root]`）のローカル Z 座標をオフセットさせ、離席・ロード復帰時に `0.0` へリセットします。
