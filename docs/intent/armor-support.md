# VRMの衣装を着脱できるフォロワー

0.8.0の衣服切替設計は[native-wardrobe.md](native-wardrobe.md)を正典とする。胴32・手33・足37による標準の排他処理へ移行し、同時に着る胴の衣服を一品にまとめる。追加枠と装備イベントによる切替は廃止した。以下の追加枠を中心にした設計は過去の記録。

ステータス: 検証待ち。元VRMの身体・下着・常時表示部分・衣服の分類、独立した装備出力、ブラウザ操作と出力描画の検査を実装。Skyrim内の着脱・持ち物会話・解散・セーブ／再読込時の状態は未検証。

0.5の既存装備の体型合わせ・標準部位への身体分割・複数フォロワーの防具パッチは[armor-fitting.md](armor-fitting.md)へ追加した。衣装分離のみの0.4の出力方式はそのまま選択できる。

## 目的と範囲

ウィザードで防具対応なし／ありを選ぶ。対応ありでは、衣服を取り除いた下着姿を無装備の身体として扱い、元VRMの衣装を着脱可能な装備へ変換する。元衣装を防御力0の全身服として追加して初期装備にする方法と、上半身・下半身・アクセサリーへ分ける方法を扱う。Skyrimの既存防具の体型合わせは、この衣装分離とは別の処理である。

原VRMとゲーム資産は変更しない。利用者のモデル、固有の構成情報、検査画像を公開リポジトリへ含めない。

## VRM側の成立条件

VRMはglTFのノード／メッシュ／primitive／材質と、人体関節などの拡張を保存する。Unityの元prefab参照や「これは上着」「これは下着」という衣服分類は標準VRMフィールドではない。残った階層・形状名・材質を候補の分類に使い、最終的にはユーザーがプレビューで役割を確定する。

独立した衣服ノードなら幾何を切断しなくても選択できる。メッシュ内の材質ごとの分離も可能だが、材質境界が必ず衣服境界になるわけではない。身体と服が一体化し服の下の身体がない入力から、完全な下着身体を自動的に復元できるとは約束しない。

髪・服・身体のskinが異なる場合も、親の変換、bind pose、元のウェイトを保って共通の出力骨格へ変換する。glTFのskin数は独立した骨格の数を意味しない。

## Skyrim側の構成

- 無装備の外観は専用種族のSkin（RACE.WNAM → ARMO → ARMA）へ置く。顔・髪と交換対象の身体を分け、胴装備を着ても顔と髪が消えない構成にする。
- 衣服は独立したARMOと、専用種族・出力NIFを指定するARMAを生成する。防御力0、Clothing種別を選べる。NPCのDefault Outfit（DOFT → OTFT）へ入れて初期装備とする。
- 標準スロットは32=Body、33=Hands、37=Feetなど。標準の独立したズボン／スカート枠はない。スカート、タイツ、重ね着、髪飾りには44–49や52–60の追加枠を割り当てられるが、用途はMOD間の慣習でありゲームの標準分類ではない。50/51は切断用なので利用しない。
- 同じ装備枠を占有する衣服は同時装備できない。ARMO/ARMAのスロット、NIFの部位パーティション、身体の表示／隠蔽を一緒に扱う。スロットは身体を服の形に自動で切り抜く機能ではない。衣服の内側の身体を残す・隠す・衣服NIFへ必要な身体を含める方針を、部位と組み合わせに応じて決める。
- 外して下着へ戻ること、上着だけ・靴だけを交換してもほかの外観が保たれること、肌や下着が服を突き抜けないことを実物で検証する。

0.3の方式は全形状へSBP_32_BODYを割り当て、顔・髪・衣服・身体を一つの外観へまとめていた。0.4ではこの固定モードを保ち、衣服対応ありの時は出力形状とARMAを分離する。元の一体外観の上へ衣服レコードだけ追加する方式ではない。

## 提案するウィザード

対応なしは現在の固定外観を維持。対応ありでは「身体・下着・常時表示の髪など」と「着脱する衣服」をプレビュー付きで分類する。元衣装をまとめた防御力0の全身服を標準の出力にし、詳細設定で複数メッシュを一品へまとめる／個別の上着・スカート・靴・アクセサリーに分ける。品名、占有枠、衣服／軽装／重装、防御力、重量、価値、初期装備を保存可能にする。分類は元ノードのindexを保持し、名前変更や重複名でも同じ入力内で再現できるようにする。

既存の鉄鎧等への対応には、その種族で使うARMA、専用骨格に合うbind pose、アバターの体型に合う鎧形状、鎧に含まれる身体と元身体の扱いが必要。種族のArmor RaceをNordにするだけでは体型保持と形状適合の証明にならない。まず元衣装の着脱を成立させ、その出力身体／部位情報を既存防具への適合にも使う設計とする。

今回の実装では身体=32、下着=52、常時表示=60をSkinの別々のAddon/NIFとして出力し、元衣装は44–49、53–59の重ね着枠へ割り当てる。同時装備品の枠の重複を拒否する。原VRMの重なりと形状を保持し、下着を基本外観へ残す。既存防具へのフィッティングと身体の隠蔽は、この分類・骨格を利用する次の実装対象であり、今回の出力を既存鎧対応済みと表示しない。

分類は入力のSHA256に結び付け、別VRMへの誤適用を拒否する。全ての有効メッシュノードを一回だけ分類し、出力した各NIFをその役割の元形状と照合する。衣服のグループをまとめる／分ける、品名、枠、種別、防御力、重量、価値、初期衣装への採用を指定する。名前だけの自動判定を確定分類にせず、ユーザーが変更し、原VRMの分類プレビューを確認できるようにする。

身体と独立した衣服・髪の骨格は、元の関節名を候補にし、モデル空間での基準位置と手足の方向・対応の一意性を検査して統合する。元の髪／服の位置のずれは保持し、ポーズの変化だけを身体から伝える。比較用の元材質とNIF用に正規化する材質も分け、透明な部品が比較画像で不透明化しないようにする。装備品の持ち物・地面表示は本体の汎用衣服を参照する。

## 完成を確認する経路

ウィザードの分類 → 複数NIF/ARMO/ARMA/OTFT生成 → レコードとパーティション、同一骨格の確認 → 下着／全衣服／一部衣服の静止・歩行・戦闘描画 → Skyrimで初期装備・脱着・交換・再起動後の状態を確認。設定なしの従来出力も維持する。
