# 複数フォロワーの同時導入

異なるMOD IDで生成したZIPを同時に導入したとき、インストール先のファイルパスが一つも重ならないようにする。モデル・テクスチャ・ESPだけでなく、再変換用の設定JSONと説明書も対象に含める。Windowsの大文字小文字を区別しない比較で、完成したZIP同士を検査する。同じMOD IDは同一MODの更新として扱う。

0.3/0.4では設定JSONと説明書を共通のルートパスで同梱していた。これらはゲームの実行時に読み込まれないが、MOD管理ツール上のファイル競合と再変換設定の上書きを起こした。0.4.1では両方を `vrm2skyrim/<mod_id小文字>/` へ移す。旧成果を再パッケージする場合、生成元が使っていた二つの旧共通パスを除去する。ESP・モデル・テクスチャの内容は変更しない。

検証: 二つの実際の配布ZIPに共通パスがないこと、ゲーム資産の全ファイルが旧版と同じバイト列であること、ZIPのCRC・マニフェスト・設定の再読み込みが成立することを確かめる。ESP内の同一セル編集と、ファイルのインストール先競合は別の対象として報告する。
