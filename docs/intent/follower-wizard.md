# VRM2Skyrim フォロワー制作ウィザード

ステータス: 0.3のソフィー版フォロワーは2026-10-11にユーザーからゲーム内確認OKの報告を受領。0.4の衣服着脱モードはゲーム内検証待ち。0.4.1の複数MOD同時導入のファイル構造は[package-coexistence.md](package-coexistence.md)を参照。

人型VRM 0/1を選び、名前・MOD名・性別/声・戦闘タイプ・成長・能力・Perk/魔法/武器・生存設定を順に決め、専用種族と骨格を持つフォロワーMODのZIPを得る。初期配置はホワイトランのキナレス聖堂。最初の会話から標準フォロワーとして勧誘できる。0.4では固定外観／元衣装の分離装備を選択できる。衣服の仕様は[armor-support.md](armor-support.md)が持ち、既存鎧のフィッティングはその次の実装対象とする。

設定を一つのJSONに保存し、ウィザードとCLIと再変換で共用する。全パイプラインの名前・ESP名・EDID・メッシュ/テクスチャのパスを同じ設定から決め、異なるMODを同時導入できるようにする。ゲームの実データから候補を読み、標準フォロワー会話が存在するボイスを選択可能にする。Perkと魔法のFormIDを推測せず、ゲームのレコードから解決する。

骨格とメッシュの形状保持は0.2の方式を継続。入力のボーン名やオブジェクト名、分割数にSophie固有の仮定を置かない。透明/マスク材質、任意の手の形状、任意/欠けた補助ボーンにも対応する。人型でない入力や必須の関節が欠ける入力は具体的な理由を返す。元VRMやゲームData/セーブを変更せず、VRMとゲーム資産をリポジトリへpushしない。

導入先・Blenderを検出/設定でき、変換中の進捗とログ、出力ZIPと確認用画像をウィザードから取得する。設定を戻って直せる。開発者専用のパスに依存しない起動手順を用意する。

検証は、独立した設定の2つのMODの名前/パス/レコードが衝突しないこと、標準フォロワーの派閥・関係・声・配置のレコード、全設定のバイナリへの反映、実際のブラウザ操作から変換まで、出力NIF/DDSの読み戻しと外観で行う。ユーザーの0.2の外観確認と0.3のソフィー版フォロワー確認を保持する。別設定や衣服着脱モードへその了承を広げない。

公開先: https://github.com/maha0525/VRM2Skyrim 。pushはユーザーから明示承認済み。
