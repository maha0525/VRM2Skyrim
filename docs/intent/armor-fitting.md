# 元の身体を保つ既存装備の体型合わせ

ステータス: 0.5で変換・身体部位分割・出力検査・ウィザード選択・防具互換パッチ作成を実装。静止・歩行・剣攻撃の描画を確認。ゲーム内の装備・脱着・同時導入は確認待ち。

利用者のVRMの身体・顔・骨格の比率を変えず、ローカルのSkyrim装備を専用体型へ変換する。元装備の身体形状を重ねず、露出する肌をVRM側の身体から補う。まず胴鎧とブーツを実物で検証し、同じ仕組みで指定した本体ゲームの胴・手・足装備を扱う。ヘルメット、盾、DLCや他MODの任意マスター解決は別の入力形式として区別する。

身体は関節と標準部位に対応する面単位で分割し、元の頂点位置・UV・ウェイト・法線を保持する。胴・前腕・ふくらはぎ・手・足の部位とARMAの優先度をそろえる。鎧だけを骨格の長さと身体表面へ合わせる。鎧の内側の身体を表示せず、露出する面は元の身体から含める。元VRMの重ね着を着たまま新しい鎧を重ねることは自動管理しない。既存衣服を外して着替える確認経路を生成READMEへ明記する。

同じ既存装備アイテムを使用するため、フォロワー本体は専用ARMAを定義し、別の互換パッチが元ARMOのArmatureへその参照を追加する。元のArmature・アイテムの数値・他種族の対応を維持する。複数フォロワーは一つの互換パッチへまとめ、最後のフォロワーのARMOだけが勝つ構成にしない。フォロワーZIPと互換パッチZIPを分け、フォロワー同士のインストールパスを共有しない。生成パッチのマスターとロード順を案内する。

入力はゲーム本体BSAの元資産であり、インストールされたBodySlide出力や別MODの置換メッシュを勝手に上書きしない。元VRM、ゲームData、既存MODとセーブは読み取りに限定する。モデル固有の対応情報と生成物はローカルに保ち、公開ソースへ含めない。

検証は元身体の形状保持、全身体面の一回だけの分類、部位とSkin/ARMAの対応、装備のウェイトとbind pose、肌の置換、既存ARMOの値と元Armatureの保持、複数マスターの参照、ZIPパスの独立性を含む。実際の出力NIF/DDSを標準の静止・歩行・剣攻撃で描画して確認し、ゲーム内の装備・脱着・同時導入は独立した確認として残す。

一次資料: [Outfit Studioの体型変換手順](https://github.com/ousnius/BodySlide-and-Outfit-Studio/wiki/Conversion-references-and-using-them)、[PyNifly作者のNIF部位仕様](https://github.com/BadDogSkyrim/BethesdaLibrary/blob/main/docs/file-formats/nif-files.md)、[xEditのTES5レコード定義](https://github.com/TES5Edit/TES5Edit/blob/dev-4.1.5/Core/wbDefinitionsTES5.pas)。これらは変換・身体の置換・部位・参照の機構を確認する資料であり、任意VRMの変換成功の証明として扱わない。
