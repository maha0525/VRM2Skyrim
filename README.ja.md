# VRM Skyrim Converter

[English README](README.md)

**VRM Skyrim Converter** は、手元の VRM アバター（`.vrm`）から **Skyrim Special Edition / Anniversary Edition** 用のフォロワー MOD（ZIP 形式）を作るローカル変換ツールです。

ブラウザで動くウィザードに沿って進めるだけで、3D モデルの変換から、衣装や防具の着脱、髪や服の揺れもの（Faster HDT-SMP）、アニメ調のトゥーン描画（Community Shaders）、戦闘スタイルや初期装備・オリジナル武器の登録まで、Mod Organizer 2 や Vortex にそのまま導入できる形で一括パッケージ化します。

---

## できること

- **ブラウザのウィザードで完結**
  5 つのステップに沿って選ぶだけで、フォロワー名・声・出会う場所・戦闘タイプ・初期装備・Perk・呪文・シャウトを設定できます。Skyrim 本体とインストール済み MOD から選べる項目を自動で読み込むため、フォーム ID を手入力する必要はありません。
- **元の衣装の着脱と、ゲーム内防具の体型合わせ**
  VRM のメッシュを「身体・下着・衣服」に分けて、ゲーム内で服を脱いだり別の鎧に着替えたりできるように変換できます。また、Skyrim 本体の防具や導入済み MOD 防具をアバターの体型に合わせて自動変形するパッチも同時に作れます。
- **髪・スカートなどの揺れもの対応（Faster HDT-SMP）**
  VRM に含まれる揺れもの設定（Spring Bone）を読み取り、Faster HDT-SMP 用の物理設定と当たり判定を自動生成します。揺れの硬さプリセットや揺らす部位の選択もウィザード上で行えます。
- **アニメ調のトゥーン描画（Community Shaders）**
  元 VRM の MToon 材質設定（影色・明暗の境界・リムライト・輪郭線など）を読み取り、Skyrim 内でアニメ調の質感を再現する専用シェーダーに対応しています。
- **オリジナル武器の同梱（GLB）**
  Blender 等から書き出した `.glb` ファイルを読み込んで、フォロワー専用の武器（片手剣・両手武器・弓・杖など）として同梱し、初期装備に持たせることができます。
- **頭身に合わせた着席位置の自動調整**
  元のアバターの脚の長さや頭身に合わせて、酒場の椅子やベンチに座ったときの腰の高さを自然に補正します。

## 必要な環境

### 変換に使う PC 環境

| 項目 | 要件 |
| :--- | :--- |
| **OS** | Windows 10 / 11（64-bit） |
| **Python** | Python 3.11 または 3.12 |
| **Blender** | Blender 4.5 LTS |
| **Skyrim 本体** | Steam 版 Skyrim Special Edition（または Anniversary Edition）がインストールされていること |

### Skyrim 側で必要な前提 MOD

基本のフォロワー機能（同行・戦闘・衣装の着脱・オリジナル武器）だけなら、**追加の前提 MOD は必要ありません**。使いたい機能に応じて、以下の MOD を Skyrim 側に導入してください。

| 使いたい機能 | 必要な前提 MOD | 備考 |
| :--- | :--- | :--- |
| **基本のフォロワー・元の衣装の着脱・オリジナル武器** | なし | Skyrim 本体（および装備やシャウトで選んだ公式 DLC / Creation）のみで動きます。 |
| **頭装備による顔・髪の表示切替** | **SKSE64** | 兜や帽子を着けたときに顔や髪を自動で隠す場合に必要です（`skse64_loader.exe` から起動）。 |
| **着席時の高さ調整** | **SKSE64** | 椅子やベンチに座ったときの高さをスクリプトで補正します。 |
| **髪や服の揺れもの（物理演算）** | **SKSE64** + **Faster HDT-SMP** | VRM の Spring Bone をゲーム内で揺らすために必要です。 |
| **トゥーン描画（アニメ調の陰影・輪郭線）** | **SKSE64** + **Community Shaders（Bottled Shaders 1.0.22 / DLL 1.9.0.0）** + **トゥーン描画用シェーダー ZIP** | 同梱の `VRM2Skyrim-Toon-Shader-0.13.0.zip` は **Bottled Shaders 1.0.22** 専用です（STEP 01 または完了画面から保存できます）。 |
| **ゲーム内の既存防具の体型合わせ** | **SKSE64** + **SkyPatcher** | 既存の鎧や兜をフォロワーの体型に合わせて着せる場合に使います。 |

## はじめかた

### 1. 初回セットアップ

リポジトリをダウンロードしたら、最初に一度だけ **`Setup.cmd`** をダブルクリックして実行してください。
Python の仮想環境（`.venv`）の作成と、変換に必要な Blender アドオン・ツールの準備が自動で行われます。

### 2. ウィザードの起動

普段使うときは **`Launch.cmd`** をダブルクリックします。
ローカルサーバーが立ち上がり、ブラウザでフォロワー作成ウィザードが自動的に開きます。

> [!TIP]
> ツールをアップデートしたときは、起動中の黒いコマンドウィンドウを一度閉じてから、もう一度 `Launch.cmd` を開き直してください。

## フォロワーを作る手順（5 ステップ）

### STEP 01: アバターと衣装・描画の設定

1. **VRM ファイルを選ぶ**
   変換したい `.vrm` ファイルを選択すると、メッシュ数やポリゴン数が解析されます。
2. **トゥーン描画の設定（任意）**
   VRM らしいアニメ調の陰影や輪郭線を使いたい場合は、**「トゥーン描画（Community Shaders 用）」** を開いてチェックを入れます。
3. **衣装の着脱と部位分け（任意）**
   ゲーム内で服を着替えさせたい場合は、「衣服・防具の分離」を **「対応あり：身体・下着・衣服を分けて着脱」** に切り替えます。
   - VRM 内の各メッシュを「身体」「下着」「衣服」「顔」「髪」などに振り分けます。
   - 「自動提案に戻す」「1品ずつ分ける」「1着にまとめる」ボタンで素早く整理でき、Blender の確認プレビューで脱衣時の見た目もその場でチェックできます。
   - ゲーム内の防具を着せたい場合は **「ゲーム内の防具をこの体型に合わせる」** にチェックを入れ、合わせたい防具を選びます。
4. **揺れもの（Faster HDT-SMP）の設定（任意）**
   VRM に Spring Bone が入っている場合、どのパーツ（髪・スカートなど）を揺らすか選択し、揺れの硬さプリセット（`0.3` / `1` / `3`）を調整できます。
5. **過去データの再表示・設定ファイルの読み込み（任意）**
   画面上部の「保存済みの作成結果」から過去に作った MOD の完了画面を開き直したり、下部の「保存した設定の読み込み」から以前保存した設定 JSON を復元したりできます。

### STEP 02: 名前と基本プロフィール

- **フォロワーの表示名・MOD 名・プラグイン名**: ゲーム内で表示される名前と、生成される `.esp` の名前を決めます。
- **性別・身長・体重**: モーションの骨格（女性／男性）と、ゲーム内での体格を設定します。
- **声の種類・結婚会話**: Skyrim 内のボイスタイプと、結婚システムへの対応を選択します。

### STEP 03: 戦闘スタイルと初期装備・振る舞い

- **戦闘プリセット**: 「片手剣の戦士」「弓の狩人」「破壊魔術師」などのプリセットを選ぶと、向いているクラスや初期武器・能力値が自動でセットされます。
- **初期武器・オリジナル武器**:
  - ゲーム内の既存武器を持たせるほか、**「オリジナル武器」** を選んで手元の `.glb` ファイルをアップロードすると、専用武器として変換・同梱できます。
  - プレビュー画像を見ながら、武器の長さや握る位置・向きを微調整できます。
- **保護属性・道徳観**: 「不死（Essential）」「保護（プレイヤーの攻撃でのみ死亡）」「通常」の切り替えや、犯罪への態度を設定します。
- **能力値・スキル・椅子の座り位置**: レベルに応じた自動計算のほか、18 種類のスキル値や体力・マジカ・スタミナの手動調整、椅子やベンチに座ったときの腰の高さ補正を設定できます。

### STEP 04: Perk・呪文・シャウト

- フォロワーに最初から習得させておく **Perk（能力）**、**呪文（Spells）**、**シャウト（Shouts）** を選びます。
- スキル系統での絞り込みやキーワード検索ができ、選択した項目は上部にタグとしてまとまるため、迷わず整理できます。

### STEP 05: 確認とパッケージ作成

- 設定内容の一覧を確認し、問題なければ **「フォロワーMODを作成」** を押します。
- 変換が走る前に「設定をJSONで保存」しておくと、あとで設定を少しだけ変えて作り直したいときにそのまま読み込めて便利です。

## Skyrim への導入方法

1. **フォロワー MOD 本体の導入**
   変換が終わると、完了画面から **MOD の ZIP ファイル** をダウンロードできます。Mod Organizer 2 や Vortex にそのままインストールして有効化し、**ホワイトランのキナレス聖堂**にいるフォロワーに話しかけて仲間に誘ってください。
2. **トゥーン描画を有効にした場合**
   STEP 01 または完了画面の **「トゥーン描画用シェーダーをダウンロード」** からシェーダーアドオンの ZIP を保存し、Community Shaders と一緒に導入してください（最初の一度だけで構いません）。
3. **既存防具の体型合わせを有効にした場合**
   SKSE64 と SkyPatcher を導入し、`SkyPatcher.ini` の `iEnableArmorPatching` と `iEnableFormlistPatching` が `1` になっていることを確認してください（完了画面の「Deploy後に確認」ボタンから導入状態を検査できます）。
4. **Outfit Studio で特定の防具を手直ししたい場合（任意）**
   完了画面の「Outfit Studioで形を仕上げる」から、変換済みの素体・骨格と防具が入った **編集用キット（ZIP）** を保存し、Outfit Studio で微調整した `.nif` を取り込んで MOD ZIP を更新できます。

## 困ったときは

### 「ウィザードの再起動が必要です」と表示される
ツールを更新したあと、古い変換サーバーが裏で動いたままになっているとこの案内が出ます。起動している古いターミナルで `Ctrl+C` を押すかウィンドウを閉じてから、もう一度 `Launch.cmd` を実行し、新しく開いたブラウザのページを使ってください。

### 既存のセーブデータでフォロワーの見た目や装備が更新されない
Skyrim は一度出会った NPC の装備や状態をセーブデータに記録します。同じプラグイン名でフォロワーを作り直したときは、まだそのフォロワーと出会っていないセーブデータで確認するか、別エリアへ移動してからコンソール（`@` または `~` キー）で `recycleactor` を実行してください。

## コマンドライン（CLI）からの変換

ブラウザのウィザードを使わず、コマンドラインから直接変換することもできます（`Convert-VRM.cmd` も利用できます）。VRM ファイルは位置引数で渡し、細かい設定はウィザードの「設定をJSONで保存」で書き出した設定ファイルを `--settings` に指定します。

```powershell
# ウィザードを起動する
Launch.cmd
# または
.venv\Scripts\python.exe wizard.py

# VRM ファイルから直接フォロワー MOD を出力する
Convert-VRM.cmd "path\to\avatar.vrm" --settings "path\to\settings.json" --output "build\my-follower"
# または
.venv\Scripts\python.exe converter.py "path\to\avatar.vrm" --settings "path\to\settings.json" --output "build\my-follower"
```
